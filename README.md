# AVIF / WebP Converter

A TypeScript web app for batch converting images between AVIF and WebP formats.

## What it does

- Converts images from AVIF to WebP and vice versa
- Batch processing for multiple images
- Preserves image quality with configurable compression
- Browser-based, no server upload required

## Tech Stack

- **TypeScript** — Conversion logic
- **Canvas API** — Image processing in the browser

## Getting Started

```bash
git clone https://github.com/teeaarbee/avif-webp-converter.git
cd avif-webp-converter
npm install
npm run dev
```
